# Sub-agent: visual fidelity

Compare the running listing page to a current Airbnb listing on desktop (~1280×800).

## Must match
- Header: rausch wordmark, search pill, user chip
- Title + Guest favorite + reviews + location
- 5-up photo grid, 8px gaps, 12px outer radius, hover dim, “Show all photos”
- Sticky booking card, rausch Reserve gradient that follows the pointer
- Guest favorite laurel block
- Photo tour: full-screen white, room nav, grouped grids
- Lightbox: charcoal full-screen, 1 / N, prev/next, ←/→, Close returns to tour
- Footer wash background

## Fail if
- Purple/generic AI palette
- Emoji used as amenity icons
- Lightbox missing keyboard nav
- Horizontal overflow at 1280 or 390
