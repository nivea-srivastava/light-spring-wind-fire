# Casa Aurora — listing clone

Pixel-faithful Airbnb listing page. Desktop is the contract; mobile must not overflow.

- No auth, no database, no `.env`
- Data: `src/lib/listing-data.ts`
- Three views: listing, photo tour, lightbox
- Architecture diagram: `/architecture` and `docs/architecture.svg`
- Prompt log: `docs/prompts.md`
- Review agents: `.agents/`
